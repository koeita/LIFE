# 🌟 LIFE — ひとつの人生

ブラウザで手軽に遊べる、本格テキスト＆カード選択式の**人生シミュレーションゲーム**です。  
0歳の誕生から学生時代、就職・結婚・子育て、趣味や資産運用、そして老後・臨終まで――1年を1ターンとして、波乱万丈な「ひとつの人生」を体験できます。

🎮 **[今すぐブラウザでプレイする](https://life.xcangcheng.workers.dev/)**

---

## ✨ ゲームの特徴

### 1. 🧬 生まれ持った才能 ＆ 16タイプMBTI性格
* 誕生時に **8大才能（天才肌、鋼の肉体、カリスマ、強運など）** から2つがランダム付与。
* **16タイプのMBTI性格診断システム**により、性格タイプに応じたステータス成長の補正・特徴が変化します。

### 2. 📊 5大ステータスと成長曲線
* **🧠 知力** / **💪 体力** / **🤝 社交** / **🎨 創造** / **😊 幸福** の5大パラメータ体系。
* 年齢や過労、シニア期の加齢・医療費リスクをリアルにシミュレート。

### 3. 🎓 青春とキャリアの多様な分岐
* **幼少期・学生時代**: 小学校の習い事（サッカー、ピアノ、プログラミング、絵画）や中学校・高校の部活動、全国大会での活躍、スカウト注目度。
* **進路・職業**: 高卒就職、大学進学、大学院、大手企業、専門職（医師・弁護士・研究者など）、フリーター、さらには**起業して年商数十億の社長**や**国会議員（選挙出馬）**まで多彩なキャリアが存在。
* **就職活動UI**: 自分の学歴やステータスで受かる企業が発光し、要件未達の企業は理由（🔒 学歴・ステータス不足）がバッジ表示されます。

### 4. 🌿 自由行動システム（いつでも実行可能）
15歳以上になると、毎年の行動カードとは別にいつでも利用できる4大メニューが開放されます：
* **💕 恋愛・家族**: 出会い、デート、プロポーズ・結婚、子どもの誕生と進学支援。
* **🌿 趣味・ペット**: 保護犬・保護猫の里親制度と年1回のふれあい、5つの本格的な趣味（料理、キャンプ、写真、盆栽、麻雀）の腕前磨き（Lv1〜Lv5名人）。
* **🏦 資産・ショップ**: 株式・インデックス投資、収益不動産オーナー、マイホーム購入（田舎古民家・中古マンション・一戸建て・タワマン）、愛車、そして**一撃500万円の海外カジノVIP勝負**。
* **🚀 キャリア・起業**: 副業（ブログ・せどり・アプリ開発等）、起業、新規事業投資、転職活動、選挙出馬。

### 5. 📸 人生アルバム（メモリアルスナップ）
* 人生の重要な節目（生誕、志望校合格、プロ契約、結婚、我が子の誕生、趣味極め、大勝負勝利、定年退職など）で、ポラロイド写真風の**メモリアルスナップ**がアルバムに自動記録されます。

### 6. 🏆 殿堂入りランキング & コレクション図鑑
* 人生の終わりに総合評価（S+〜Fランク）と最終スコア、人生の軌跡を描く**レーダーチャート＆人生ステータス推移グラフ**を表示。
* 歴代のベスト人生TOP10や、全実績・全職業・全才能を埋めるコレクション図鑑、SNSへの結果シェア機能を搭載。

### 7. 🛡️ リアルタイム自動セーブ ＆ リロード耐性
* ターンごとの自動セーブにより、ブラウザをリロードしてもスタート画面に戻らずプレイ中画面へ直接復帰。
* イベントや転職活動中のリロードによる不正なやり直し（リセマラ）を防止するターン永続化を実装。

## 🕹️ 画面構成と遊び方

```
┌────────────────────────────────────────────────────────┐
│ [🔊 音ON] [🏠 メインメニュー]                         │
│ [名前・年齢・肩書] [総資産] [健康状態]                │
├────────────────────────────────────────────────────────┤
│ 🧠知力  💪体力  🤝社交  🎨創造  😊幸福 (ミニステータス)│
├────────────────────────────────────────────────────────┤
│ [🎯 行動・メニュー]   [📊 ステータス詳細]   [📜 人生の記録] │
│                                                        │
│ 🌿 自由行動クイックメニュー (恋愛・趣味・資産・キャリア)│
│                                                        │
│ ┌──────────────────────────────────────────────────┐   │
│ │ 1. 🍼 [行動カード1]                              │   │
│ │ 2. 🧸 [行動カード2]                              │   │
│ │ 3. 😴 [行動カード3]                              │   │
│ └──────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

1. **行動カードを選ぶ**: 毎年提示される3枚のアクションカードから1つ選んで人生を進めます。
2. **トーストを確認**: 行動結果とステータス変化が画面下部に表示されます（自動で消えないためじっくり確認可能）。
3. **イベントへの対応**:
   * **イベントがある場合**: 画面をタップするとトーストが消えてイベントモーダルが開きます。
   * **イベントがない場合**: トーストが出たままでも次の行動カードを押してサクサク進められます。
4. **自由行動を活用**: お金に余裕ができたら、投資やマイホーム購入、趣味やペットで人生を豊かに彩りましょう。

## 🛠️ 技術スタック

* **言語・マークアップ**: HTML5, CSS3, JavaScript (Vanilla ES6+)
* **ライブラリ依存**: なし（Zero-dependency）
* **オーディオ**: Web Audio API（シンセサイザー波形生成方式、外部mp3等不要）
* **描画**: HTML5 Canvas（エンディングステータスグラフ描画）
* **データ永続化**: LocalStorage API
* **デプロイ環境**: Cloudflare Workers (GitHub連携自動デプロイ)

## 💻 ローカル環境での起動方法

特別なビルドツールや Node.js サーバーは不要です。

```bash
# 1. リポジトリをクローン
git clone https://github.com/koeita/LIFE.git
cd LIFE

# 2. index.html をお使いのブラウザで開く
# (ダブルクリック、または以下のコマンド等)
start index.html
```
